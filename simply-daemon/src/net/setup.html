3 · Discord bot

Open Discord Developer Portal ↗
  1. New Application → name it.
  2. Bot tab → Reset Token → copy it into “Bot token” below.

  4. General Information → copy the Application ID below.
Invite the bot to your server ↗

After saving, open the invite link to add Lumina to your guild (you need “Manage Server” there).
